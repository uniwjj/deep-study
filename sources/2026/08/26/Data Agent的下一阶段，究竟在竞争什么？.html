Data Agent的下一阶段，究竟在竞争什么？

作者：Data+AI 发表：2026-08-26 11:01 来源：https://mp.weixin.qq.com/s/fpoFf_K0Yqf6A8wQHpQLIg 下载：2026-08-26 11:48

近日，IDC发布《IDC MarketScape：中国 Data Agent 2026年厂商评估》，袋鼠云凭借在数据开发、数据治理、数据分析及Agent应用等方面的综合能力，被定位于主要厂商（Major Players）类别。

在IDC的定义中，Data Agent已经不局限于数据查询与分析，而是覆盖数据层、数据管理层、数据开发层和业务层：从数据分类、质量管理、开发修复，到分析洞察、知识检索和辅助决策，Agent正在越来越深入地参与企业数据运行过程。IDC预计，到2028年，60%的中国500强企业将部署企业级Data Agent。

这一趋势背后，真正值得关注的，是企业Data与AI之间的关系正在发生变化。

Data Agent正在成为Data与AI之间的“运转机制”

过去几年，企业已经分别建设了数据平台与AI应用。

一端负责采集、开发、治理和供给数据，另一端通过模型、知识库和Agent寻找业务应用。两端能力都在快速成熟，但真正进入企业生产环境之后，一个问题越来越突出：

数据如何持续进入智能应用，智能应用产生的经验又如何重新沉淀回企业的数据与知识体系？

这决定了企业AI究竟是一个个独立应用，还是能够形成持续进化的智能体系。

IDC此次报告给出了一个重要信号。Data Agent的能力边界正在沿着数据生命周期不断向前延伸，数据集成、治理、开发、查询、分析逐渐被Agent重新组织；与此同时，MCP、A2A等协议快速成熟，也在降低不同数据软件、Agent与Skills之间的协同门槛。

因此，Data Agent更深层的价值，在于开始成为连接数据基础设施与智能应用的一层“运行机制”。

它一方面进入数据平台内部，通过Agent参与数据开发、治理和分析，提高数据生产效率；另一方面又把治理后的数据、指标、知识和语义持续提供给上层业务Agent。

而业务Agent在使用过程中形成的新问题、新知识、新规则和新经验，又可以重新沉淀为企业的数据资产、知识和Skills。

数据与智能由此开始真正咬合起来。

战略承接：以“Data+AI智能飞轮”连接数据与智能

这也是袋鼠云提出Data+AI智能飞轮的核心逻辑。

企业数据经过持续治理，形成能够被AI准确理解和调用的数据基础，进一步供给智能分析与Agent应用；智能应用进入真实业务现场后，又会持续产生新的反馈、规则和业务知识，这些内容重新沉淀回数据平台，形成新的指标口径、知识规则、业务语义与Skills，为下一轮智能应用提供更准确的上下文。

数据持续供给智能，智能持续反哺数据。

承载这套飞轮运转的核心，是袋鼠云“一体两翼”的整体业务架构。

“一体”即数栈·AI Ready多模态数据智能平台，打通结构化、半结构化与非结构化数据的统一存储计算、开发治理和资产开放，构建企业数据从采集到供给的完整链路。

“两翼”则进一步将数据能力转化为业务价值：通过数据智能与空间智能，面向智能决策、Agent应用、数字孪生等业务场景形成智能化应用。

Data Agent恰恰位于其中非常关键的位置——向下进入数据生产过程，向上连接数据与业务应用，让Data+AI智能飞轮真正运转起来。

灵瞳Data Agent，让Agent进入数据全生命周期

围绕这一思路，袋鼠云已经将Agent能力持续嵌入数栈。

灵瞳Data Agent以元数据库、产品文档和企业知识库为知识基础，融合主流大模型能力，目前已经覆盖数据开发、数据治理、数据分析、产品操作四大场景。

在数据开发环节，Agent可以辅助数据任务生成、报错分析与修复；在治理环节，可以进行血缘分析、质量规则生成；在分析环节，通过自然语言完成数据检索、指标分析与归因；同时通过产品操作Copilot降低复杂数据平台的使用门槛。

经实践验证，灵瞳Data Agent整体提效40%。IDC也在报告中指出，袋鼠云产品矩阵涵盖开发、治理与服务，Agent能够贯穿数据生命周期，并具备灵活的SaaS化与私有化部署能力。

这意味着，Data Agent带来的变化已经不只是给数据平台增加一个自然语言入口，而是在改变传统的数据工作方式。

下一阶段，竞争的是“数据×Agent”的持续进化能力

IDC认为，随着GenAI和Agent的发展，数据与分析的重要性正在进一步提升；实时数据集成、更大规模的数据计算，以及数据治理、数据现代化正在重新成为企业建设重点。

与此同时，IDC也指出，多模态数据管理、数据治理以及垂直行业专家经验将成为数据厂商的重要积累；未来更多Data Agent还将围绕Skills、统一语义和更加主动的数据管理方式继续演进。

这意味着，Data Agent的下一阶段竞争，很难仅通过某一个Agent功能拉开差距。

决定企业AI能否持续深入业务的，将是底层数据能否持续AI Ready，Agent能否真正参与数据全生命周期，以及每一次业务应用产生的经验能否重新沉淀、复用并进一步提升下一次智能应用的效果。

此次进入IDC MarketScape中国Data Agent主要厂商类别，是对袋鼠云Data+AI体系建设的一次阶段性认可。

行业落地：沉淀know-how，驱动规模化复制

Data Agent能力的真正价值，最终要在行业场景中兑现。

目前，袋鼠云数栈已深度服务国央企集团、能源矿产、先进制造、水利水务、高校教育、金融、港口交通、新锐零售等行业，积累了超过5000+家企业客户的落地实践。在央国企集团场景，Data Agent帮助客户打通集团管控与分子公司经营数据，构建穿透式指标体系与风险预警能力；在能源矿产与先进制造领域，完整的数据治理链路与实时数据处理能力，支撑设备监控、质量管理与生产优化的精细化运营；在港口交通、水利水务等空间属性突出的行业，数据智能与空间智能协同，驱动数字孪生与智能调度真正进入业务决策。

每一个行业场景的深度落地，都在持续向平台回流行业语义、业务规则与场景经验，沉淀为可复用的行业解决方案能力。平台越懂行业，解决方案的复制与迭代速度就越快——这本身，也是Data+AI智能飞轮在行业维度的另一种转动方式。

未来，袋鼠云将继续以Data+AI智能飞轮为核心，通过数栈AI Ready多模态数据智能平台持续夯实数据基础，以灵瞳Data Agent推动数据开发、治理和分析方式升级，并进一步连接数据智能与空间智能应用，让企业的数据资产与智能能力在真实业务运行中持续积累、持续进化。
