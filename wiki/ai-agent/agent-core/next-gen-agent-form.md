# 下一代 Agent 形态探索（TopoClaw 与 Venom）

> 2026 Agent 大会「前沿探索与超级Agent论坛」演讲，演讲者**王吉宏**（OPPO 高级算法工程师，OPPO 研究院-数据智能研究部-拓扑 Lab，团队网址 https://madeagents.ai/）。

核心命题：下一代智能体由**两条正交的跃迁**共同定义——**从孤岛走向链接**（打破数字世界信息孤岛，TopoClaw）与**从数字走向物理**（突破物理世界感知屏，Venom）。

## Agent 的演进

从生成内容到调用工具，再到跨主体、跨空间、跨时间承担任务：

| 2022 | 2023 | 2024 | 2025 | NEXT |
|------|------|------|------|------|
| 对话式智能（回答） | 工具增强（调用） | 单机执行（完成） | 多 Agent 编排（协作） | What Next？ |

> 能力边界的变化，比单纯的模型规模变化更值得关注。

## 当前智能体困境：孤岛与隔阂

瓶颈正在从「会不会回答、会不会执行」，转向**信息孤岛的打通**和**数字世界与物理世界的链接**：

- **信息**：用户信息分散在各个设备孤岛，不同的需求分散在不同的设备；缺失的系统层——跨设备、跨用户、跨环境
- **执行**：不同的需求分散在不同的设备
- **关系**：真实协作被隔离在系统外
- **感知**：数字世界隔绝了物理世界信息

## 两条正交的跃迁（框架）

| | 孤立运行 | 设备 / 用户 / Agent 互联 |
|---|---|---|
| **数字 · 孤立** | 聊天助手 | 连接型数字助手（**数字世界的探索——TopoClaw**，从孤立到链接） |
| **物理 · 孤立** | 孤立的单体机器人 | 持续多主体智能体生态（可连接 · 可持续 · 可行动 · 可追责）（**物理世界的探索——Venom**） |

## TopoClaw：跨设备、跨用户的智能体探索

总览：双拓扑架构。核心组件（第 6 页架构图）：

- **核心运行时服务**：生命周期、记忆、工具与技能、调度器、消息总线
- **跨拓扑引擎**：物理拓扑路由、社交拓扑编排
- **跨拓扑边界防御策略流水线**：拓扑上下文监控、动态权限降级、分布式策略执行、沙箱与语义审计
- **执行平面**：设备执行、社交执行
- 参与者：用户、好友、公共助手、同事、家人、个人助手

### 设备拓扑（DEVICE TOPOLOGY）：让任务在最合适的终端上执行

| 终端 | 能力 |
|------|------|
| 手机 | 消息入口 · GUI · 位置 · 穿戴信号 |
| 电脑 | PC 中枢：代码 · 工具 · GUI 自动化 · 数据处理 |
| 平板电脑 | GUI · 学习文件 · 娱乐休闲 |
| 边缘设备 | 环境感知 · 本地执行 |

统一编排（状态汇总 · 结果回执），五步流程：**01 任务投递 → 02 能力路由 → 03 端侧执行 → 04 结果回流 → 05 状态更新**。同一任务 · 同一回执口径 · 同一用户感知。

### 社会拓扑（SOCIAL TOPOLOGY）：把真实关系带进智能体协作

- **01 关系**：好友系统承载真实社会结构（公共助手 / 同事 / 好友 / 用户 / 家人 / 个人助手）
- **02 身份**：决定协作中的「谁是谁」
- **03 权限**：决定「谁能看见和做什么」

### Demo 演示（原文示例）

- 跨设备：「我电脑上有一个叫劳务合同的pdf，你帮我找一找里面甲方的姓名和电话，然后发条短信问他什么时候有时间」
- 跨用户：「帮我创个群，叫'内部小聚群'，拉好友小B进来，然后问他最近有没有时间一起共进晚餐。」

## Venom：从数字走向物理——全自主多模态智能体探索

数字世界 → 物理世界：

| 数字世界 | 物理世界 |
|---------|---------|
| 任务离散 | 事件连续（能力扩张） |
| 回合制交互 | 自主交互（难度放大） |
| 文本记忆 | 多模态记忆 |

> 当数字走向物理，智能体架构必须如何改变？

### 持续多模态 Agent 必须同时回答三个问题

- **RQ1 连续感知**：如何从无边界音视频构建可更新、可抢占的状态？
- **RQ2 主动个性化**：何时说、何时行动、何时沉默？
- **RQ3 长期记忆**：如何压缩经历，又能回到原始证据？

> 感知、介入与记忆不是三个插件，而是相互影响的联合闭环（joint optimization）。

### Venom 总体架构（第 12 页）

- **顶层 · 人格与目标**：
  - A. 人格配置：BIG5 特质（开放性、尽责性、外向性、宜人性、神经质）+ 行为偏置（规划深度、任务坚持度、主动性水平、激活强度、响应风格）。固定配置：每轮加载到上下文
  - B. 目标状态：层次化目标树 + 当前激活目标。示例：GO 协助用户完成现实任务 → G1 取水（G1.1 定位水杯、G1.2 抓取并递送—激活）、G2 找钥匙（G2.1 检索近似位置、G2.2 前往并确认）；策略层：状态与更新（用户位置、水杯位置）、下一步：规划动作
- **中层 · 多模态输入**：视频 / 音频（VAD）/ 文本；近期记忆（2 分钟）：近期对话与事件
- **决策层**：
  - 快通道：根据人格和目标进行快速决策，默认不进行记忆检索，低时延，适合无对话场景
  - 慢通道：持久记忆检索 → 场景综合 → 回复/行动（工具调用）
- **底层 · 统一记忆存储层**：L1 事实与关系（确定事实、用户偏好与长期状态）、L2 片段与事件（交互片段、事件过程）、L3 视觉帧（关键帧与视觉片段）；按需下钻检索（逐层下钻 L1→L2→L3，证据充分即停止）；后台异步回写（所有输出统一写入记忆：事件片段 → 语义事实 → 实体与关系归纳，按用户画像组织与索引化）；上下文压缩与摘要

### 连续感知：用事件—状态—策略—记忆组织连续现实

五步闭环：**01 连续音视频 → 02 事件流 → 03 Agent 状态 → 04 主动策略 → 05 语音 / 工具 / 行动**；行动回执 / 环境变化重新进入事件流，闭环持续更新。共享时间轴 τ（t0→t1→t2→t3→t4→t5）；异步记忆闭环：当前状态 → 情景片段 → 语义事实 → 用户画像 / Agent 自我模型。**记忆改变下一时刻的感知重点与主动阈值。**

### 长期记忆：记忆不是无限上下文，而是可逆的分层压缩

| 层 | 名称 | 时间尺度 | 内容 |
|----|------|---------|------|
| M3 | 人格与关系记忆 | 长期 | 用户画像 · Agent 自我模型 · 关系历史 |
| M2 | 语义记忆 | 跨天—跨月 | 稳定事实 · 规律 · 偏好 · 因果假设 |
| M1 | 情景记忆 | 分钟—小时 | 事件片段 · 参与者 · 动作与结果 |
| M0 | 当前状态 | 秒—分钟 | 当前场景 · 说话人 · 进行中的任务 |

> experience → episode → fact → persona。高层结论是压缩视图；原始证据是可以回放、更新与质疑的底座。
