# 袋鼠云 Data Agent：Data+AI 智能飞轮与灵瞳 Data Agent

## IDC 报告与 Data Agent 定义

- IDC 发布《IDC MarketScape：中国 Data Agent 2026年厂商评估》，袋鼠云凭借在数据开发、数据治理、数据分析及 Agent 应用等方面的综合能力，被定位于**主要厂商（Major Players）**类别。
- 在 IDC 的定义中，Data Agent 已不局限于数据查询与分析，而是覆盖**数据层、数据管理层、数据开发层和业务层**：从数据分类、质量管理、开发修复，到分析洞察、知识检索和辅助决策。
- IDC 预计：**到 2028 年，60% 的中国 500 强企业将部署企业级 Data Agent**。

## Data Agent 成为 Data 与 AI 之间的"运转机制"

过去几年，企业分别建设了数据平台与 AI 应用：一端负责采集、开发、治理和供给数据，另一端通过模型、知识库和 Agent 寻找业务应用。进入生产环境后，核心问题逐渐突出——**数据如何持续进入智能应用，智能应用产生的经验如何重新沉淀回企业的数据与知识体系？** 这决定了企业 AI 终究是一个个独立应用，还是能够形成持续进化的智能体系。

Data Agent 更深层的价值，在于开始成为连接数据基础设施与智能应用的一层"运行机制"：

- **向下**：进入数据平台内部，通过 Agent 参与数据开发、治理和分析，提高数据生产效率
- **向上**：把治理后的数据、指标、知识和语义持续提供给上层业务 Agent
- **回流**：业务 Agent 在使用过程中形成的新问题、新知识、新规则和新经验，重新沉淀为企业的数据资产、知识和 Skills——数据与智能由此真正咬合起来

文章指出，[[agent-mcp-protocol|MCP]]、A2A 等协议快速成熟，正在降低不同数据软件、Agent 与 [[agent-skills-system|Skills]] 之间的协同门槛；Data Agent 的能力边界沿数据生命周期延伸，数据集成、治理、开发、查询、分析逐渐被 Agent 重新组织。

## 战略承接：Data+AI 智能飞轮

袋鼠云提出 **Data+AI 智能飞轮**：企业数据经过持续治理，形成能够被 AI 准确理解和调用的数据基础，进一步供给智能分析与 Agent 应用；智能应用进入真实业务现场后持续产生新的反馈、规则和业务知识，重新沉淀回数据平台，形成新的指标口径、知识规则、业务语义与 Skills，为下一轮智能应用提供更准确的上下文。

> 数据持续供给智能，智能持续反哺数据。

承载飞轮运转的核心，是袋鼠云"一体两翼"整体业务架构：

- **一体**：数栈·AI Ready 多模态数据智能平台——打通结构化、半结构化与非结构化数据的统一存储计算、开发治理和资产开放，构建企业数据从采集到供给的完整链路
- **两翼**：数据智能与空间智能——面向智能决策、Agent 应用、数字孪生等业务场景形成智能化应用

Data Agent 位于其中关键位置：向下进入数据生产过程，向上连接数据与业务应用，让飞轮真正运转起来。

## 灵瞳 Data Agent

袋鼠云将 Agent 能力持续嵌入数栈，灵瞳 Data Agent 以**元数据库、产品文档和企业知识库**为知识基础，融合主流大模型能力，覆盖**数据开发、数据治理、数据分析、产品操作**四大场景：

| 场景 | 能力 |
|------|------|
| 数据开发 | 数据任务生成、报错分析与修复 |
| 数据治理 | 血缘分析、质量规则生成 |
| 数据分析 | 自然语言数据检索、指标分析与归因 |
| 产品操作 | Copilot 降低复杂数据平台使用门槛 |

- 经实践验证，灵瞳 Data Agent **整体提效 40%**
- IDC 报告指出：袋鼠云产品矩阵涵盖开发、治理与服务，Agent 能够贯穿数据生命周期，并具备灵活的 SaaS 化与私有化部署能力
- 文章观点：变化已不只是给数据平台增加一个自然语言入口，而是在改变传统的数据工作方式

## 下一阶段竞争：数据×Agent 的持续进化能力

IDC 的看法与判断：

- 随 GenAI 和 Agent 发展，数据与分析的重要性进一步提升；**实时数据集成、更大规模的数据计算、数据治理、数据现代化**重新成为企业建设重点
- **多模态数据管理、数据治理、垂直行业专家经验**将成为数据厂商的重要积累
- 未来更多 Data Agent 将围绕 **Skills、统一语义和更加主动的数据管理方式**继续演进

因此，Data Agent 的下一阶段竞争很难仅通过某一个 Agent 功能拉开差距。决定企业 AI 能否持续深入业务的三个要素：

1. 底层数据能否持续 AI Ready
2. Agent 能否真正参与数据全生命周期
3. 每次业务应用产生的经验能否重新沉淀、复用并提升下一次智能应用的效果

## 行业落地：沉淀 know-how，驱动规模化复制

- 数栈已深度服务**国央企集团、能源矿产、先进制造、水利水务、高校教育、金融、港口交通、新锐零售**等行业，积累 **5000+ 家企业客户**落地实践
- 央国企集团：打通集团管控与分子公司经营数据，构建穿透式指标体系与风险预警能力
- 能源矿产与先进制造：完整数据治理链路 + 实时数据处理，支撑设备监控、质量管理与生产优化的精细化运营
- 港口交通、水利水务等空间属性突出的行业：数据智能与空间智能协同，驱动数字孪生与智能调度进入业务决策

每个行业场景的深度落地持续向平台回流行业语义、业务规则与场景经验，沉淀为可复用的行业解决方案能力——平台越懂行业，解决方案的复制与迭代就越快，这本身也是 Data+AI 智能飞轮在行业维度的转动方式。
