## Hologres：AI 时代的多模态数据底座

**全模态实时数仓引擎 + Agent/模型基建**，不再是单点"能查向量"。

- **第一层 · 全模态实时数仓引擎**：
  - 全模态数据：结构化 / 半结构化（Variant）/ 非结构化（Blob）
  - 全场景检索：OLAP · KV · 向量 · 全文 · 图 · 空间地理
  - 仓内湖上一体化：同一引擎完成从接入到多模态分析
- **第二层 · Agent 与模型基建**：
  - 长记忆服务：Agent Memory 持久化 · 精准召回 · 跨会话连续
  - 可观测数据底座：大模型交互日志实时写入 / 查询 / 分析
- **交付层 · 面向行业场景**：AI Function、百炼全托管、混合检索、电商 · 零售 · 金融行业实时数据服务

## AI Function：一份数据、一份计算、多模分析

大数据+AI Function：all-in-one，实现"一份数据、一份计算、多模分析"。整体功能架构三大块：

- **数据查询（多模融合）**：在线推荐（点查）、BI 报表（OLAP 分析）、检索分析（全文检索）、RAG（向量检索）、向量化（混合检索）、内容生成（AI 推理）
- **数据加工（一份计算 Data+AI）**：数仓分层加工（ODS/DWD/DWS/ADS 层，Dynamic Table 增量计算）；AI Function（gen、Embedding、transcribe、translate……）；托管模型（百炼）：Embedding 模型、Qwen-image 模型（wan 模型）、Qwen-vl 模型、AI 节点模型（独享 GPU）、Deepseek 模型
- **数据存储（多模数据）**：向量、文本、JSON（内部存储：结构化&半结构化数据）；Paimon、Iceberg、MaxCompute（数据湖：结构化&半结构化数据）；图片、PDF、PPT、视频（OSS：非结构化数据，Object Table）

亮点能力：多模态数据一键入仓、索引构建；一键多模式数据计算——一条 SQL 完成全增量近实时自动加工；一键部署百炼模型——AK 一键部署，开箱即用；一站式 AI 数据分析——向量、全文、OLAP、点查、AI 推理。

### AI Function 功能清单

AI Function：内置 AI 函数，通过标准 SQL 直接调用大模型，实现非结构化数据向量化、多模推理、智能内容生成等 AI 应用场景，**兼容 PostgreSQL 生态**。基于阿里云海量算力池，自动调用大模型，SQL 化处理结构化和非结构化数据，简化 AI 开发，统一数仓和 AI 服务。

- **内容生成与转换**：ai_parse_document（文本识别：pdf/word/图片等多模态数据识别，转换成文本）、ai_fix_grammar（语法纠错）、ai_gen（智能内容生成：通过提示词调用 LLM 生成文案、图片、视频）、ai_summarize（智能文本摘要）、ai_translate（多语言智能翻译）
- **文本理解与分析**：ai_extract（信息结构化提取：从输入文本中提取用户指定的标签信息）、ai_similarity（语义相似度计算）、ai_classify（文本分类）、ai_analyze_sentiment（情感倾向分析）、ai_rank（智能打分：对输入进行相关性打分）
- **向量化与文本切片**：ai_embed（embedding：对输入进行量化，产生向量）、ai_chunk（长文本分段）、ai_transcribe（语音转文本）
- **数据安全**：ai_mask（敏感信息脱敏）

### 一键调用百炼模型

购买 Hologres 模型资源 → 控制台一键部署模型 → SQL 调用 AI Function 消耗 token。适用场景：智能搜索与推荐（商品语义检索、相似商品推荐）；实时风控与异常检测（违规内容识别、IOT 设备故障报警）；智能内容生成（营销文案生成、广告视频素材创作、语音合成）；语音处理与交互（语音转写、会议纪要生成）。

方案优势：零代码集成（仅需 SQL 即可调用 AI 函数，分析师无需学习 Python）；实时高性能（内核级函数调用，百亿级向量亚秒级响应）；数据零搬迁（直接在大数据系统中完成全流程，数据不出库，安全可管控）；灵活和低成本（内置多种百炼模型一键部署，按 Token 调用按需使用）。

预估日均 Token：轻量场景（文本分类/摘要）10 万~50 万 Token；中等场景（语义检索/实时风控）50 万~200 万 Token；重度场景（大规模向量化/复杂生成）200 万~1000 万 Token。

### 典型应用场景与客户案例

**场景 1：多模数据加工与混合检索**。Hologres 方案：Object Table 感知 OSS 上非结构化数据变化；Dynamic Table 增量对新增数据调用 AI Function 进行加工和 embedding，可以结合结构化数据一起加工，同时存储加工结果；应用高性能查询 Holo 表，使用向量+全文+OLAP 混合检索分析多模数据。客户画像：数仓存储结构化数据、有非结构化与结构化混合检索分析诉求、非结构化数据量大、希望一个系统一条 SQL 完成实时多模数据加工与分析；典型行业：车辆网、智能驾驶、电商、新媒体等。

- 客户案例：某 SaaS 系统相似票据推荐（全球领先企业管理云 SaaS 公司，ERP 系统场景：相似流水单据自动生成发票推荐、合同模板推荐）。流程：OSS（合同、发票等数据）→ Object Table → ai_parse_document（解析非结构化数据语料表）、ai_chunk（长文本切片）、ai_embed（数据 embedding）→（Dynamic Table 增量刷新）→ 向量检索/全文检索双路召回 → 召回 Top 1。性能结果：单并发平均 Latency 72.8ms，相比其他检索系统提升 40%；40 并发 14 万条评测集总处理时长 1080.43 秒，平均 Latency 7.6ms；混合检索查询准确率 84.46%。业务价值：毫秒级检索效率、统一数据存储（无需导出至其他检索系统，统一数仓团队和算法团队的开发体验）、成本更低、使用门槛更低（纯 SQL 开发 AI 服务）。
- 客户案例：某零售客户多模数据检索（国内大型连锁便利店企业，货物摆放智能识别：门店货架照片与货架模版匹配，发现错放、缺货；使用 tongyi-embedding 模型、Qwen3-vl 多模态推理）。业务价值：差异校验准确率 90% 以上；纯 SQL 一个平台完成混合检索与分析；系统架构从数据平台升级为多模数仓。

**场景 2：智能营销内容生成**。通过 Hologres 打通素材、生成与投放分析全链路：Object Table 读取原始非结构化物料 → 物料表与 object table 结合生成新的物料素材（图片）→ 大模型生成分镜脚本 → 调用 wan 模型生成视频 → 投放数据使用 Hologres 分析。典型行业：游戏、电商、互联网、广告。

- 客户案例：某游戏客户广告视频生成（国内 TOP 游戏公司自研广告投放平台）。痛点：投放与素材脱节（广告素材、脚本版本和投放效果数据之间缺少统一沉淀，难以形成优化闭环）；系统多运维复杂（多个系统导致后端团队分别同步数据、运维管理，架构复杂且冗余）；创意生产效率低（每做一条广告从头构思主题、筛选素材、撰写脚本、制作视频，周期较长）。方案：object table 获取原始物料素材 → ai_gen 生成新物料 → 大模型生成分镜脚本 → wan 模型生成广告视频 → 人工核对后投放。业务价值：全 SQL 链路、统一管理游戏素材（Hologres 表结构与广告投放数据混合分析）、端到端自动化（覆盖角色变体、分镜脚本到视频合成全流程，秒级/分钟级产出）、高效扩展性。

**场景 3：多语言语音智能处理**。面向客服、游戏、智能驾驶、医疗、SaaS 和跨境业务等高语音密度行业。Hologres 方案：Object Table 读取原始语音素材；调用百炼大模型对语音文件处理，包括说话人识别、语言识别、ASR 转写等能力统一存储在 Hologres 的语音表中；应用层直接读取语音表内容，做情感分析、工单生成等。帮助企业从"听录音"升级到"看数据、做决策、闭环管理"。

## AI 助手：数仓从入门到精通

数仓客户常见使用困境："开发靠折腾，运维靠经验，分析靠手工，决策靠猜测"——POC 新客上手门槛高；数仓开发需求开发低效（复杂场景反复调试 SQL，缺乏调优智能解读）；数仓运维被动式救火（系统黑盒强、巡检能力弱、故障感知不及时、根因定位需跨系统拼凑信息）；数据分析师查数门槛高（无法自助分析、依赖数仓团队）。

Hologres AI 助手：围绕 Hologres 实例，基于资深数仓专家沉淀的多个 Skills，提供多 agent 协同支撑数仓全生命周期问题，包含知识问答、实例诊断、SQL 调优等丰富的数仓场景，助力数仓从入门到精通，0 代码，0 门槛，开箱即用。技术组件：Holo Agent 框架、Qwen Code Agent、Holo 元仓、Holo 知识库、Holo 大账号调用、模型服务（百炼大模型 qwen 系列）。

四大 Agent：

| Agent | 能力 |
|-------|------|
| 知识问答（QA Agent） | 售前技术方案咨询、产品规格推荐、功能使用答疑 |
| 数仓开发（Develop/Optimize Agent） | 数仓搭建教程、SQL 调优建议、功能开发最佳实践 |
| 数仓运维（OPS Agent） | 实例资源诊断、慢/错 SQL 诊断、成本治理 |
| 数据分析（Data Analyze Agent） | 自然语言访问数据、报表可视化生成、数据解读与趋势预测 |

多场景 Agent 覆盖：实例资源诊断、慢 SQL 诊断与优化、数据智能分析、SQL 生成与优化——开发、运维、诊断、数据分析多场景一站解决 Hologres 全生命周期问题。使用：Step1 官网开通 AI 助手；Step2 在控制台和 Holoweb 使用 AI 助手。核心能力：产品使用咨询（基于 Hologres 知识库）；CPU/内存诊断（快速诊断水位异常及解决方案）；慢 SQL 诊断（全实例慢/错 SQL 诊断及单 SQL 诊断与调优）；运维报告（实例级全方位诊断报告，涵盖资源、成本、SQL、表等多个维度）。

## 长记忆服务：Agent 记忆一站式解决方案

典型场景：01 AI Coding 助手（跨会话持续积累项目上下文记忆，Agent 越用越懂你的代码库）；02 电商购物 Agent（深度记住用户偏好与消费禁忌，因果级个性化推荐）；03 AI 伴学（持续追踪知识断点与遗忘曲线，精准诊断薄弱环节并动态调整学习路径）；04 金融理财顾问（基于持仓历史与重大生活事件变化，个性化风控与资产配置建议）。

架构：OpenClaw、Hermes、AI Coding、其他 Agent → **Mem0 标准接口** → Hologres 长记忆服务（Mem0）→ Hologres（HGraph 向量引擎、LLM、Embedder、Rerank）→ Hologres 多模态记忆存储。

优势（依托 Hologres 多模态检索能力与 Mem0 框架生态）：**开箱即用**（开源框架 Mem0 100% 兼容，API 快速接入，Agent 应用无缝迁移）；**全托管服务、成本更优**（服务全托管无需串联多组件免运维；支持记忆精炼，大模型 Token 消耗显著降低）；**一站式解决方案**（系统架构简洁）；**高可扩展性**（云原生分布式架构，业务灵活扩展，可支持百亿级记忆数据）；**高性能**（高性能记忆实时写入、记忆写入即可查；毫秒级向量/全文/图检索，性能、准确率领先）。记忆无遗忘、Agent 共享、免运维。

AI 助学场景 Demo（页面数据）：听力正确率 80%、阅读正确率 65%、单词听写 15/20、课堂参与举手 3 次、距离考试 52 天、遗忘曲线 3 天后 35%、关注阅读细节题、"明天加入阅读细节定位练习"——流程：教师反馈 → 家长查询 → AI 定制计划 → 长期追踪。
