# 腾讯 WorkBuddy 数据实践

> DataFun Agentic AI Summit「AI Native数据湖让企业Agent拥有统一的智能数据底座（腾讯云专场）」演讲（腾讯云大数据专场）：**腾讯 WorkBuddy 基于 AI DLC 打造持续进化…**（封面标题后半被遮挡，仅可辨认至此；全文主题为 WorkBuddy 的数据底座与数据处理实践）。与 [[workbuddy-context-engineering]]（WorkBuddy 上下文工程——从模型到 Harness 的产品设计）互补：本页聚焦 WorkBuddy 的数据底座与数据处理实践。

## 三个绕不开的数据难题

1. **数据量增长异常快**——任务量爆发，数据体量增速远超预期，处理能力必须足够弹性。数据体量月增速 >100%（虚线数值为示例参考，请按实际数据校准）
2. **超大字段的处理压力**——对话、文档、图像等多模态字段极大，常规引擎读取与解析都很吃力。单字段最大 1GB+
3. **众多数据方、高权限要求**——数据需求方数量多、角色杂，权限边界必须清晰且可审计。数据需求方 10+

## 选型：数据湖计算 DLC

一个 Serverless 底座，五个最看重的能力：

| # | 能力 | 说明 |
|---|------|------|
| 01 | **Ray x Spark 双引擎** | 一份算力同时驱动数据处理、后训练与在线推理 |
| 02 | **Serverless 弹性** | 算力秒级伸缩，按任务/时长计费，免集群运维 |
| 03 | **Xpark 多模态引擎** | SQL-First AI Function，50+ 多模态/LLM 算子 |
| 04 | **TCLake 元数据** | 数据对象 + AI 对象统一纳管，全流程血缘 |
| 05 | **MCP / Open API** | 底座可被 Agent 编排调用，串联数据与训练 |

## 接入 AI DLC 后的整体架构

数据源（业务数据、图片/文档、行为日志）→ 数据湖存储（对象存储 + 数据湖：海量低成本、TCLake；**存算分离——存储与算力独立扩展**；统一权限——一处授权处处生效）→ DLC 计算（Serverless 引擎：Spark x Ray、Xpark 多模态；流水线含 Spark 准备 → Arrow → Ray 训练等环节；**双引擎协同，数据不跨系统**）→ 消费层（BI 报表、后训练/推理、各数据方；MCP/Open API，底座可被 Agent 编排调用）。

## 场景一：Agent 数据处理与血缘

### 超大字段的高效处理

痛点：对话、长文档等单条记录字段极大，常规按行读取会拖慢一切。

DLC 方案：
- **列式存储**——只读用到的字段，避开整行大对象
- **存算分离**——大字段与元数据分开存储，检索、统计更轻
- **Xpark 多模态引擎**——50+ 多模态/LLM 算子承接重解析，峰值临时扩容

收益：超大字段任务耗时下降 60%、任务成功率 99%、扫描数据量大幅下降。

### 引擎性能：实测数据

同一批数据、同一条管线——切换 DLC 前后的真实对比：
- **同数据处理耗时 5h → 1h**——同一批数据端到端跑完，从 5 小时降到 1 小时，吞吐提升 5 倍
- **CPU 使用率下降 80%**——按同等负载换算，处理同样的数据只需约 1/5 的算力开销
- **100% 兼容 Spark，存量作业零改动迁入**

（WorkBuddy 同数据集实测，口径以内部报告为准）

### MLOps：串联数据与后训练

背景：数据与训练割裂、靠人工串联。流水线（实际运行界面）：
1. **Agent 轨迹/反馈沉淀入湖**（API）
2. **Xpark 数据处理、特征提取**（API）
3. **Ray Train 后训练 SFT/RL**（API）
4. **评估/回流，反哺 Agent**

轨迹与评估自动回流数据湖，持续反哺后训练——**Agent 越用越聪明**。

收益：数据-训练交付周期下降 70%、人工搬运下降 90%、流程可复用。

### TCLake：全流程自动血缘

数据对象 + AI 对象统一纳管——数据加工、特征工程、模型训练、模型服务、Agent 轨迹/记忆均「直接注册」，引擎直接注册元数据与运行状态，数据到模型全链路可追溯：可追溯、可分析影响、合规可交代。

收益：问题排查时间下降 80%、额外成本 0、血缘图谱实际界面覆盖 95%+。

## 场景二：数据处理资源与权限

### 弹性算力，从容应对增长

痛点：数据体量增速远超预期，固定集群要么闲置浪费，要么高峰不够。

DLC 方案：
- **线性扩展**——处理能力随资源同步线性增长；CPU/GPU 异构算力池统一纳管、动态调度。数据量增长 → 算力线性扩展，算力随数据量线性增长，每个任务按需获取
- **按需获取**——每个任务按处理量与时效独立申请，Serverless 按任务/时长计费，闲时按量收缩

收益：峰值处理时延下降 65%、启动速度分钟级、闲时算力成本 → 0。

### 精细化权限，服务多数据方

痛点：数据需求方多、角色杂，权限边界必须清晰且可审计。

方案：数据需求方（算法/模型训练、BI 分析、风控、运营/数据科学）→ **DLC 统一权限中心**（库/表/行/列级授权）→ TCLake 治理、最小授权、全程可审计；操作审计全程留痕。

收益：授权到位、越权风险 → 0。
